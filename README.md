功能：

-查看港鐵巴士實時位置

-行走部分特別路線(K53S, K66A)及各路綫特別班的巴士都會被特別標註

限制：

-無法顯示沒有開啓實時位置的巴士(如加班車和已到達總站之巴士)

-未能查詢巴士過往行蹤

Function:

-Track real-time location of MTR buses

-Buses operating at some special routes (K53S, K66A) and special departures of each route are highlighted

Limitation:

-Buses without real-time location cannot be shown (eg. additional departures and buses which arrived the terminus)

-Past whereabouts of buses cannot be checked
